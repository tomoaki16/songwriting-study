# 1.5x進度対応｜半年追加トラック

## 目的
標準26週カリキュラムと「5曲完成」の最終目標は維持する。

現在の学習実績では、理解確認・ギター実演・Studio One / Song Applyまで含めても当初想定より速く進められている。この余力を、理論の先食いではなく **作曲・分析・耳・語彙の反復回数を増やすこと** に使う。

## 1.5xの意味
- 1日の学習時間を1.5時間へ増やす意味ではない
- 標準2ユニットを到達基準付きで終えられたら、追加1ユニット相当を入れるイメージ
- 追加課題は標準CLEAR後に実施する
- 追加課題未完了だけを理由に標準Dayを未完了にはしない
- 制作が重いMonth 5〜6では、追加学習を減らして完成を優先する

## 追加トラックの優先順位
1. **短作曲 / 小さな設計演習**：8〜16小節を白紙から作る
2. **プロ曲分析 → 再現 → 変形**：分析だけで終わらせず自作へ転用
3. **メロディ作曲の反復**：モチーフ、リズム、着地音、跳躍、反復・変形
4. **耳トレ**：Degree / Function / Cadence / リズム / 音色を実音で判断
5. **Voice Leading / Bass motion**：共通音、半音・全音移動、内声、ベースライン

## Month 1｜基礎を白紙作曲へ変える
### 標準
音程 / スケール / コード / Function / Cadence / リズム / 構成。

### 追加
- 8小節ミニ作曲を1〜2本
- 条件例：
  - 安定 → 憂い → 期待 → 期待を外す
  - 最後までIへ帰らない
  - 同じコードでAメロ版 / サビ版をリズムだけで作り分ける
- 作成後、Degree / Function / Cadence / リズム / 自分の聴感で説明
- 5〜10分の短い耳トレ：T/S/D、V→I、V→VI、V STOP等

### 追加到達
**学んだ理論を、問題に答えるだけでなく8小節を白紙から作るために使える。**

---

## Month 2｜メロディとVoice Leadingを厚くする
### 標準
長短調 / 代理コード / ドミナント / ノンダイアトニック / メロディ / テンション。

### 追加
- 毎週1本程度、8〜16小節のミニ作曲またはメロディ演習
- 同一進行へ3種類のメロディ
  - コードトーン中心
  - 順次進行中心
  - 跳躍＋モチーフ変形
- 強拍・ロングトーンがコードに対して何度かを確認
- 4コードの各声部を追い、共通音 / 半音 / 全音 / 大跳躍を比較
- 同じ上物コードで、ルート / 転回 / 経過的ベースを比較
- プロ曲のメロディ2〜4小節を月4〜6例程度、分析 → 再現 → 変形

### 追加到達
**欲しいキャラクターから複数のメロディ案を作り、採否を説明できる。**

---

## Month 3｜パート語彙を量で増やす
### 標準
ドラム / ベース / ギター・キーボード / 緩急。

### 追加
- 各Weekでプロ曲の短い例を、余力があれば2〜3例へ増やす
- 各例は **Analyze → Reproduce → Role → Transform → Song Apply**
- ドラム：同じコードに3パターン＋「何を変えないか」も説明
- ベース：ルート中心 / リズム中心 / 接続中心 / メロディ的から最低3案
- ギター等：コード / アルペジオ / 単音 / テクスチャ / 休符を役割別に比較
- セクション差を、追加だけでなく削除 / 音域 / 密度 / 役割交代でも作る

### 追加到達
**各パートで手癖以外の選択肢を複数持ち、目的から選べる。**

---

## Month 4｜曲全体を解剖し、完成判断を鍛える
### 標準
Song 01の設計 / 展開 / 分析 / Version 1完成。

### 追加
- 完成曲2〜3曲を「曲全体」で解剖
- セクションごとの主役 / 密度 / 音域 / 休符 / 楽器の入り抜き / サビ導線を記録
- Song 01の弱い8〜16小節へ、リファレンスの原理を1つだけ移植
- 「足す案」と「引く案」を必ず比較
- Song 01が予定より早く完成した場合のみSong 02を前倒しする。ただしSong 01の完成判定を甘くしない

### 追加到達
**1曲を局所ではなく、全体の流れとして診断できる。**

---

## Month 5｜Production耳トレへ移行
### 標準
録音 / 音作り / Mix / リファレンス比較。

### 追加
- 週2回程度、5〜10分のA/B耳トレ
- 音量差 / Pan / EQ帯域 / Compression / Reverb / Delayを1要素ずつ比較
- 変更内容を伏せて、先に「何が変わったか」を言語化してから答え合わせ
- 同じ問題に「アレンジで直す案」と「Mixで直す案」を作る
- 新規理論を増やすよりSong 02 / 03の修正回数を増やす

### 追加到達
**音の違和感に対し、どの工程を疑うべきか耳から仮説を立てられる。**

---

## Month 6｜新規学習より制作反復
### 標準
Song 03〜05完成、5曲ブラッシュアップ。

### 追加
- 原則として独立した新規授業は増やさない
- 詰まった箇所だけ必要なプロ曲2〜8小節へ戻る
- 5曲を横比較し、同じ弱点が繰り返されているか確認
- 余力は新曲追加ではなく、修正回数 / 録り直し / 判断精度へ使う

### 追加到達
**必要な知識を自分で取りに行き、完成まで判断を止めずに回せる。**

---

## 半年間の追加目標の目安
標準目標に加え、無理のない範囲で以下を狙う。

- 8〜16小節の短作曲 / 設計演習：**12〜18本**
- プロ曲の短区間分析・再現・変形：**15〜20例**
- 曲全体の構成 / アレンジ解剖：**4〜6曲**
- 耳トレ：**Month 1〜5で短時間継続**

数を埋めること自体はCLEAR条件にしない。制作が重い時期は減らす。

## 最重要ルール
**1.5倍ペース = 1.5倍の知識を詰め込むことではない。**

余力は、
**説明 → 発見 → 再現 → 変形 → 白紙作曲 → 自作曲Apply → 採否**
の回数を増やすために使う。

半年後は、知っている理論項目数ではなく、**5曲を完成させながら、自分の耳と言葉で音楽的判断をできる範囲がどれだけ増えたか**で評価する。
