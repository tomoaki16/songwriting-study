# Month 4｜1曲を完成させる制作力

## 月間目標
ここまでの知識を統合し、**アイデアを1曲の形にまとめる能力**を身につける。
理論学習中心から制作中心へ比重を移し、Month 3で学んだドラム・ベース・ギターのパートライティングを実曲の中で何度も書き直す。

---

## Weekごとのテーマ

* **Week 13**: 曲の設計
* **Week 14**: 展開を作る
* **Week 15**: リファレンス分析＋パート修正
* **Week 16**: 完成まで持っていく

---

## 学習項目

### Week 13｜曲の設計
* **事前設計**: 曲のテーマ / 感情 / 主役 / BPM / キー / 曲構成 / セクションごとの役割 / 盛り上がりのピーク
* **追加設計**: 各セクションでドラム・ベース・ギターが「何をする / 何をしない」を簡単に決める

### Week 14｜展開を作る
* **アレンジによる展開**: 同一コード進行でも、ドラム / ベース / ギター / 音域 / リズム / ボーカル / ハーモニーを変えることで展開を作る
* **重要テーマ**: 増やすだけでなく、休符・省略・音域変更・役割交代で変化を作る

### Week 15｜リファレンス分析＋パート修正
* 制作中の曲ごとにリファレンス曲を設定し、構成 / BPM / 音数 / 楽器配置 / 盛り上げ方を比較する
* 「自分の曲がショボい」を一括りにせず、Composition / Part Writing / Performance / Sound / Mixへ分解する

### Week 16｜完成まで持っていく
* 完璧を目指して永遠に修正せず、Version 1として一旦完成させ評価・記録する
* 残った弱点はSong 02以降の課題へ引き継ぐ

---

## フレーズ獲得トレーニング

Month 4でも継続する。ただし教材用の別フレーズ作成ではなく、**制作中に詰まった箇所から逆算してプロ曲を探す**。

例:
* サビ前のドラム導線が弱い → リファレンス曲のサビ前2小節を分析
* ベースが単調 → 同じテンポ感の曲のベース接続を分析
* ギターが邪魔 → ボーカル中のギター配置・休符を分析

分析したら、そのままコピーせずSong 01 / Song 02の条件に合わせて作り直す。

---

## 分析課題

* **Week 13**: 目標とする曲の構成図と主役パートの変化を記録
* **Week 14**: Aメロ→Bメロ→サビで「何が増えたか / 減ったか / 変わったか」を分析
* **Week 15**: リファレンス曲と自作曲を比較し、「なぜ弱く聞こえるか」を要素分解する

---

## 実践課題

* **Week 13**: Song 01の各セクションについて主役と各パートの役割を一行で書く
* **Week 14**: Aメロ→Bメロ→サビの展開を、追加だけでなく削除・休符・音域変化も使って作る
* **Week 15**: 最も弱い8〜16小節を選び、ドラム / ベース / ギターのうち最低1パートを書き直す
* **Week 16**: Version 1として書き出し、次曲への改善点を3〜5個に絞る

---

## DTM個人レッスンの使い方

Month 4は**完成度を引き上げるための外部レビュー**として使う。

* Song 01の完成前バージョンを持ち込む
* 「どこが弱いか」だけでなく、「自分はここが原因だと思う」を先に提示する
* 先生には、曲全体を聴いたときの改善優先順位を確認する
* 特にパートライティングとミックスを混同しないよう、「これはフレーズの問題か、音の問題か」を確認する
* レッスン後は指摘を全部直さず、効果の大きい順に修正する

## 月末到達基準

* [ ] 最低1曲（Song 01）を完成と判断して音源として書き出している
