# Month 2｜コード進行・メロディと理論分析

## 月間目標
Month 1の基礎から進み、**自分の曲で何が起きているかを理論的に分析できる土台**を作る。同時に、理論を後付けの説明だけにせず、欲しい響きや流れを先に考えてコード・メロディを選ぶ練習を始める。

この月からDTM個人レッスンを開始し、Song 01の骨格を制作する。

> テキスト全60項目中45項目（75%）を半年の標準範囲とする。A/B分類は `textbook-reference.md` を参照。

---

## Weekごとのテーマ
- **Week 5**: 長調・短調の機能とコード進行を分析する
- **Week 6**: ノンダイアトニックコードを分析し、狙って使う
- **Week 7**: メロディを理論と耳の両面から分析する
- **Week 8**: コード・メロディ・テンションを統合しSong 01を分析する

## 自作曲の理論分析
Song 01について最低限以下を記録する。
1. Key / Major・Minor / 使用スケール
2. セクションごとのコード進行
3. Degree
4. コード機能と緊張・解決
5. ダイアトニック外コードとその説明
6. ベース音 / 転回形 / 分数コード
7. 主要メロディ音のコードに対する度数
8. 7th / 9th / add9等のコードカラー・衝突・解決
9. 偶然できた箇所 / 理論を使って狙った箇所

説明できない箇所があってもよい。**説明できない箇所を特定できること自体を学習成果**とする。

## フレーズ獲得トレーニング
毎週少量でも **分析 → 模倣 → 変形 → 自作曲へ応用** を行う。
- Week 5〜6: コード進行2〜8小節＋ベース音
- Week 7〜8: メロディ2〜4小節＋コードに対する度数
- コピー後、キー / コード / リズム / 音域のいずれかを変更する
- Song 01へ考え方を1つ以上応用する

## DTM個人レッスン
- Month 1短曲またはSong 01途中版を持ち込む
- 自分で良い点 / 違和感 / 原因仮説を用意する
- 先生の判断との違いを確認する
- レッスン後最低1か所を修正しBefore / After比較する
- 理論の正誤確認だけでレッスン時間を消費せず、制作判断・アレンジ・音の聞こえ方を中心に使う
