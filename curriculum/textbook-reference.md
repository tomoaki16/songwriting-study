# 使用テキスト対応表

## 6か月での理論学習方針

使用テキスト全60項目のうち、**45項目（75%）を6か月の標準学習範囲**とする。
目的は本を完読することではなく、半年後に一般的なポップス / ロック系の自作曲について、**キー・スケール・コード構成音・ディグリー・コード機能・主要なノンダイアトニックコード・メロディとコードの関係を分析し、「なぜこの響きになっているか」をある程度説明できる状態**になること。
さらに重要項目については、分析だけでなく**狙った響き・緊張と解決・コードカラーを自作曲へ使える状態**を目指す。

学習深度を3段階に分ける。
- **A｜使用レベル**: 理解 → 実曲分析 → DAW/ギターで確認 → 自分で例を作る → 自作曲へ応用する。
- **B｜分析レベル**: 理解 → 実曲で発見・説明 → 簡単な再現まで。自在に使えることまでは要求しない。
- **C｜発展参照**: 標準45項目には含めない。存在と用途を知り、自作曲や分析で必要になったとき参照する。

### カバー率
- A：32項目
- B：13項目
- **A+B：45 / 60項目 = 75%**
- C：15項目

## 自作曲の理論分析フォーマット

Month 2以降、制作曲は節目ごとに以下を分析する。
1. Key / Major・Minor / 使用スケール
2. セクションごとのコード進行
3. ディグリー表記
4. Tonic / Subdominant / Dominant等の機能と緊張・解決
5. ダイアトニック外コードの検出と説明
6. ベース音・転回形・分数コードが進行へ与える効果
7. 主要メロディ音のコードに対する度数（特に強拍・ロングトーン）
8. 7th / 9th / add9等のコードカラー、テンション、衝突・解決
9. 「偶然そうなった箇所」と「理論を使って狙った箇所」を区別する

### 半年後の最低到達基準
自作曲について上記1〜8を自力＋テキスト参照で分析でき、説明できない箇所を特定できること。

### 半年後の発展到達基準
コード機能、セカンダリードミナント、サブドミナントマイナー、分数コード、sus/add9、基本テンション等から選び、**欲しい効果を先に言語化してから意図的に作曲へ使用し、使用前後を比較できること。**

## 運用ルール
1. 日別Issue作成前に、この対応表と対象Monthの `curriculum/monthN.md` を確認する。
2. Issue本文に `## 📖 使用テキスト` を置き、ページ番号とその日の到達深度（A/B）を書く。
3. A項目は原則 `Learn → Analyze → Practice → Apply → Review`、B項目は `Learn → Analyze → Practice` まで行う。
4. 45項目を一度に詰め込まず、Month 1〜2で新規理論を集中学習し、Month 3〜6は自作曲分析・制作の中で反復する。
5. Month 2以降の楽曲制作では、最低1回「自作曲の理論分析フォーマット」を実施する。
6. C項目は必要時に参照し、学習した場合はログへ記録する。
