## 作曲中の現行案｜2026-09-16本人申告

- Aメロ1周目：**Eadd9 → G#m7 → A7 → B7**。各小節の歌い出し **F# → F# → G → A**（9th→7th→7th→7th）。少し不安定な響きを本人が好む。冒頭2小節が最も聴き返したいフック候補。
- Aメロ2周目：冒頭2小節の歌うリズムは1周目と同じ。2小節目G#m7の歌い出しを **F# → B** に変え、少し明るく盛り上げる。終盤Am7でメロディーを下げ、Bメロへ気持ちよく接続。2周目の全コード変更範囲は未確認。
- Bメロ採用案（2026-09-19）：**F#m → A6 → D → Eadd9｜F#m → A6 → D → B**。キーE基準のDegreeは **Ⅱm → Ⅳ → ♭Ⅶ → Ⅰ｜Ⅱm → Ⅳ → ♭Ⅶ → Ⅴ**。上声のF#を共通音として維持し、ベースは徐々に上昇させる。Aメロ後にあえて大きな和声展開を作らず、F#m→A6→Dの反復で停滞感とフラストレーションを蓄積し、最後のB→サビ頭Eで期待を解放する。旧案 F#m→A7→C#m7→B7｜F#m→G#m→A→B は、後半のⅡ→Ⅲ→Ⅳ→Ⅴがサビへの方向を早く明かし、狙いに対してベタに感じたため不採用。コード進行はギターで実音確認して正式採用。ベースとドラムはBメロまで仮案。
- サビ頭8小節の和声確定案（2026-09-19更新）：**Eadd9 → G#7 → C#m7 → G#m7｜D#dim → E → A / Adim → B**。7小節目はAからAdimへ変化する1小節。G#7はC#m7へ向かうV/vi。以前のE→G#→C#m→G#m｜D#dim→E→A→Bから、1〜4小節を7th/add9化し、7小節目にAdimを追加。変更後の和声はギターで実音確認して採用済み。**サビのメロディーは未作成**。過去に記録した歌い出し・山型／谷型の輪郭案は現行メロディーとして扱わない。
- メロディーはAメロとBメロまであり、Bメロは2026-09-19時点で一旦完成。**サビのメロディーは未作成**。コード構成音以外の音も含まれるため、経過音かどうかは前後関係を確認して判定する。
- 学習法：既存の歌ったフレーズを尊重し、要所の音とコードの関係を後から分析する。個々の音を理論から順に指定してメロディーを組み立てない。

## Bメロ進行の採用判断｜2026-09-19

- 正式採用：**F#m → A6 → D → Eadd9｜F#m → A6 → D → B**。
- 共通上声F#の役割：F#mのRoot → A6の6th → Dの3rd → Eadd9の9th。後半はF#m→A6→Dまで同じ関係を反復し、最後のみB上の5thへ変わる。
- A6はF#m7/Aと同じ構成音で、F#mから響きを大きく切り替えずに継続できる。
- DはキーEでは**♭Ⅶ**（♭Ⅵではない）。Eメジャーのダイアトニック外で、同主短調またはMixolydian由来として説明できる。ただし採用理由は機能名より、F#を保った停滞感と実聴を優先する。
- ベースはF#を保持せず徐々に上昇する。上声の停滞と低音の上昇を分担させる。進行変更はギターを弾きながら実音で判断済み。
- ４小節目のEadd9で一度Tonicを見せ、２回目はEadd9へ戻らずBで止める。反復の終端だけを変えてサビ頭Eへの期待を最大化する。

## サビ頭の和声変更｜2026-09-19

- ギターで伴奏を弾き、実音で比較して正式採用：**Eadd9 → G#7 → C#m7 → G#m7｜D#dim → E → A / Adim → B**。
- 7小節目はAとAdimで1小節を分割する。
- G#7はC#m7へのSecondary Dominant（V/vi）。A→Adim→Bは実音で採用したクロマティックな接続。AdimはAを共通音として保ち、C#→C、E→E♭と下げた後にBへ進む。次のBへの標準的なPassing diminishedならA#dimになるため、Adim自体をPassing dimとは記録しない。具体的なコード音価・ボイシング・ベースは未記録。

### Aメロ
Week 3で、反復内の対比を使って後半のAm7を効果的に聞かせる案を採用。

1周目候補：
**E → G#m → A7 → B7**

2周目候補：
**E → G#m → A7 → Am7**

本人聴感：2周目のAm7がより効果的になった。

Aメロ末のAm7は、B7を追加して未解決感を作る案も比較したが、**Am7で一度着地して曲のトーンが変わる効果を本人が好むため現状維持**とした。

### Bメロ｜2026-08-26確定
#### 1周目
**F#m7 → A → C#m7 → D#dim**

Degree：
**IIm7 → IV → VIm7 → VIIdim**

Function：
**S系 → S → T系 → D系**

本人の意図：
**「S→Sで浮遊感をもって継続 → VIm7で少し落ち着く → VIIdimで不安定さと次の展開を期待させる」**

D#dim → F#m7では、Iへの解決期待を外しつつ違和感なく次周へ戻れると確認。
本人表現：**「期待を外しながら前に進む」**。

#### 2周目
**F#m7 → G#m7 → A → B**

Degree：
**IIm7 → IIIm7 → IV → V**

本人の意図：
**「ここはサビに向かって、素直に前進させた」**。

1周目で曖昧さ / 浮遊を維持した後、2周目はII→III→IV→Vと階段状に上げてサビへの方向を明確にする。

### サビ頭
**E** を第一候補として採用。

B → E = **V → I / D → T**。
本人聴感：**「着地と同時に次の展開（サビの始まり）を感じる」**。

## 作曲法の制作チェック

既存コード／ギター素材から、声のリズムまたは歌詞の一行を核に2〜4小節の仮歌を2案作る。Aとサビのフックを比べ、モチーフをどこで反復・変形するか、Bが何を変えてサビへつなぐかを記録する。歌詞のアクセント・音域・息継ぎを確認し、仮歌＋最小伴奏で全曲を通してからアレンジする。[作曲法の学習軸](../curriculum/composition-method.md)を参照。現在地は2026-09-15の本人申告を優先し、未確認部分はDAW状態で確かめる。既存の仮ベース・仮ドラムを仮歌と合わせて聴き、採否を検討する。
