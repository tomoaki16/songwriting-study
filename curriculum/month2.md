# Month 2｜コード進行・メロディ＋Song 01骨格

## 月間目標
Month 1の基礎から進み、**自分の曲で何が起きているかを理論的に分析できる土台**を作る。同時に、理論を後付けの説明だけにせず、欲しい響きや流れを先に考えてコード・メロディを選ぶ練習を始める。

Month 1から使っている既存自作曲をSong 01として継続し、現在のイントロ〜Bメロを分析・修正しながら、**サビを含む曲全体の骨格**まで進める。

DTM個人レッスンは、Month 1で定めた開始条件を満たした時点で開始する。

> テキスト全60項目中45項目（75%）を半年の標準範囲とする。A/B分類は `textbook-reference.md` を参照。

## Month 2共通運用
毎週、次の流れを原則とする。

**Learn → 既存曲Analyze → Studio Oneで再現 → Song 01の4〜16小節へApply → Before / After → 採否 → Review**

理論課題を別ファイルで完結させず、必ずSong 01へ最低1か所つなげる。

### 指板・Chord Toneトレーニング（Month 2以降の継続項目）
コードを見たときに、ギター / ベース上で「使える音」を具体的な弦・フレットへ変換できる力を、独立した暗記課題ではなく作曲・アレンジと並行して育てる。

原則として各Weekで少量ずつ、実際に扱うコードを使って次を行う。
1. コード名 → 構成音（Root / 3rd / 5th / 7th等）を出す
2. 構成音をギターの複数弦・複数ポジションで探す
3. そのコード上で短い単音フレーズ / オブリ / ベース接続を作る
4. Root中心 / 3rd・7th中心 / 共通音・半音接続等を比較する
5. Song 01〜05で実際に使い、耳で採否する

最終的には、よく使うKey / コードについて **「コード名 → 構成音 → 指板上の候補 → 欲しい役割に応じて選択」** を短時間で行える状態を目指す。全指板の丸暗記を先に完成させることは目的にしない。

準備するもの：

## 作曲法の主学習期｜Weeks 5–8

[作曲法の実践手順](composition-method.md)に沿って、コード分析から歌える一曲の骨格へ進む。

- **Week 5–6**：Song 01の既存コードに対し、声／ギターで2〜4小節の短い案を2種類作る。強拍・長音とコードの関係を確認し、理論の適合より聴感を優先する。
- **Week 7**：2〜4音または短いリズムを核に、反復、音高だけの変形、リズムだけの変形を試す。Aメロとサビのフック候補を歌い、言葉のアクセント、音節数、息継ぎと歌える音域を確認する。既存メロディーがないときは新規案を作る。
- **Week 8**：A/B/サビで何を残し何を変えるかを決め、仮歌＋既存コード進行／Bメロまでの仮ベース・仮ドラムを使い、未制作区間は最小伴奏で全曲を通す。サビの主要音とコードの関係を分析し、フックと構成を耳で採否する。フルアレンジはMonth 3で進める。

月末の作曲面の到達基準は、Song 01の **発想の核・フック候補・モチーフの反復と変形・歌詞／仮歌・セクション対比** を示し、骨格を通して聴けること。既存の9項目理論分析は継続する。

### Week 7の運用修正｜2026-09-16

Song 01には既に本人が弾きながら歌って付けたメロディーがある。Week 7の中心は、そのメロディーを録音して聴き、Aメロのフック、反復と変化、Bメロへの移行、サビの山と谷を判断すること。コードトーン／非コードトーン、経過音、強拍の度数は**気になる箇所を直す材料が必要なときだけ**2〜4小節・目立つ数音を扱う。全音の採譜・全音分類・毎回の指板演習はクリア条件から外す。Day 1の実践目標は2026-09-16の結果で達成済み。これ以降のIssueは[作曲法の運用](composition-method.md)を優先する。

## 感情と知覚の作曲法｜Week 7–8に追加
[音と感情の作曲法](emotion-and-perception.md)の単位1〜3を、Song 01の既存メロディーとコードを使って学ぶ。Week 7で旋法・音域・奏法・期待が印象をどう変えるかを短いA/B比較で確認。Week 8でサビE→G#→C#mと旧E→B→C#m、A7→Am7等を**同じ歌・テンポ・音量**で比較し、陰り・前進・解決感を本人の言葉で記録する。普段の直感では思いつかない候補を1つは試す。全音の採譜やコード外音の網羅的分類は求めない。
