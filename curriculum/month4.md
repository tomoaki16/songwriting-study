# Month 4｜1曲を完成させる制作力

## 月間目標
ここまでの知識を統合し、**アイデアを1曲の形にまとめる能力**を身につける。理論学習中心から制作中心へ比重を移し、Month 3で学んだパートライティングを実曲で反復する。

新規理論を大量に増やす月ではない。Month 1〜2で学んだ理論をSong 01へ戻し、**自分の曲で何が起きているか説明し、必要なら理論を使って狙って修正する**。

---

## Weekごとのテーマ
- **Week 13**: 曲の設計＋理論設計
- **Week 14**: 展開を作る
- **Week 15**: リファレンス比較＋自作曲理論分析
- **Week 16**: 完成・分析・次曲への引継ぎ

## Week 13｜曲の設計＋理論設計
曲テーマ / 感情 / 主役 / BPM / Key / 構成 / 盛り上がりのピークを設計する。各セクションで各パートが何をする・しないかを決める。

加えて、理論を狙って使う候補を**1〜2個だけ**先に決める。例：サビ前にDominant感を強める / SDmで切なさを作る / 分数コードでベースを滑らかにする / add9でコードカラーを変える。理論を使うこと自体を目的にしない。

## Week 14｜展開を作る
ドラム / ベース / ギター / 音域 / リズム / ハーモニーを変え、追加だけでなく休符・省略・役割交代で展開を作る。Week 13で設定した理論上の狙いが実際に聴感へ効いたかBefore/Afterで確認する。

## Week 15｜リファレンス比較＋自作曲理論分析
リファレンス曲と構成 / BPM / 音数 / 楽器配置 / 盛り上げ方を比較する。同時にSong 01を以下で分析する。
1. Key / Scale
2. コード進行
3. Degree
4. Function / 緊張・解決
5. ノンダイアトニック
6. Bass / inversion / slash chord
7. メロディ主要音のDegree
8. 7th / 9th / add9 / tension / avoid
9. 偶然できた箇所 / 狙って作った箇所

説明できない箇所は「未解決」として残し、必要ならテキストへ戻る。

## Week 16｜完成まで持っていく
Song 01をVersion 1として完成・書き出しする。理論分析から修正価値が高いものだけ修正し、理論的に複雑にするための変更はしない。残った弱点はSong 02以降へ引き継ぐ。

---

## フレーズ獲得トレーニング
制作中に詰まった箇所から逆算してプロ曲の2〜8小節を探し、再現 → 役割分析 → 変形 → 自作曲へ応用する。

## 実践課題
- **Week 13**: 各セクションの主役・各パートの役割＋理論的な狙い1〜2個を記録
- **Week 14**: A→B→サビを、追加・削除・休符・音域変化で展開
- **Week 15**: 最も弱い8〜16小節をパート面で修正し、Song 01の9項目理論分析を実施
- **Week 16**: Version 1を書き出し、次曲への改善点3〜5個を記録

## DTM個人レッスン
Song 01完成前版と自分の理論分析を持ち込む。先生には理論テストではなく、**理論上の狙いが実際に音楽的効果として伝わっているか、パートライティングと音作りのどこを直すべきか**を確認する。レッスン後は効果の大きい指摘から修正する。
