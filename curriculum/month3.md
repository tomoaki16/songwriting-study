# Month 3｜リズムセクションとバンドアレンジ

## 月間目標
「全部の楽器を鳴らす」発想から離れ、**各瞬間で何を聴かせるのか、そのために各パートが何を担当するのか**を考えてアレンジできるようになる。

この月はドラム・ベース・ギターの**パートライティング集中月**とする。ただしMonth 3で習得完了とはせず、Month 4〜6で実曲を通じて反復する前提で進める。

---

## Weekごとのテーマ

* **Week 9**: ドラム
* **Week 10**: ベース
* **Week 11**: ギター・その他のパート
* **Week 12**: アレンジと緩急

---

## 学習項目

### Week 9｜ドラム
* **構成要素・技法**: Kick / Snare / Hi-hat / Ride / Crash / Tom / 基本ビート / 8ビート / 16ビート / フィル / ゴーストノート / ベロシティ
* **判断テーマ**: 何を叩くかだけでなく、どこで変化させるか、どこでは変化させないかを考える

### Week 10｜ベース
* **役割・技法**: ルート弾き / 5度 / 3度 / 経過音 / クロマチックアプローチ / オクターブ / コードチェンジへの接続 / キックとの関係
* *重要テーマ*: 「ベースを動かす＝良い」ではなく、「ルート維持」「リズム作成」「コード接続」「メロディ的移動」を目的別に使い分ける

### Week 11｜ギター・その他のパート
* **ギターの役割**: コード / リズム / リフ / アルペジオ / オブリガート / 単音フレーズ / テクスチャ / 空間作り
* *重要テーマ*: 常にストロークせず、ボーカル・ベース・ドラムとの役割重複を確認する

### Week 12｜アレンジと緩急
* **アレンジ手法**: Density（音数・密度） / Register（音域） / Dynamics / 楽器の追加・削除 / セクション間のコントラスト / サビへの導線 / ブレイク / ユニゾン / Call & Response

---

## フレーズ獲得トレーニング

各Weekで、対象楽器について最低1つは以下を行う。

1. プロ曲の2〜8小節を選ぶ
2. 対象パートをDAW等でできる範囲で再現する
3. コードに対する音、リズム、休符、セクション内の役割を分析する
4. そのままコピーせず、別コード進行・別テンポ・別リズムへ変形する
5. Song 01またはSong 02へ考え方を応用する

**目的は「フレーズを覚える」より、「なぜそのフレーズがそこで成立しているか」を理解し、別条件でも作れること。**

---

## 分析課題

* **Week 9**: 既存曲のドラム（キック位置、スネア位置、ハイハット、フィル、セクションによる変化）をDAW上で再現する
* **Week 10**: ベースについて、ルート維持 / リズム作成 / コード接続 / メロディ的移動のどれをしているか分類する
* **Week 11**: ギターについて、コード / リフ / アルペジオ / 単音 / 休みの切り替えを記録する
* **Week 12**: 複数のプロ曲で各セクションの「主役」を記録し、入る楽器・消える楽器・音域・リズム密度を観察する

---

## 実践課題

* **Week 9**: 同じコード進行に3種類のドラムパターンを作る
* **Week 10**: 同じコード進行に3種類のベース（1. ルート中心 / 2. リズム重視 / 3. 経過音あり）を作る
* **Week 11**: 同じセクションに対し、コードストローク / アルペジオ / 単音・オブリ中心の3パターンを作る
* **Week 12**: Aメロ→Bメロ→サビで主役、音数、音域、リズム密度を意図的に変える

---

## DTM個人レッスンの使い方

この月は個人レッスンとの相性が最も高い。

* Song 01の同じ8〜16小節について、自分で作ったドラム・ベース・ギターを持ち込む
* 「何となくダサい」「まとまらない」をそのまま質問せず、自分なりに原因を仮説化する
* 先生に、**どのパートを直すと最も効果が大きいか**優先順位を確認する
* 可能ならその場で先生の考え方・修正例を聞き、自分の判断との差を記録する
* レッスン後は同じ箇所を自分で作り直し、修正前後を比較する

## 月末到達基準

* [ ] 各楽器を「何となく入れる」のではなく、そのパートを入れる理由を説明できる
* [ ] ドラム・ベース・ギターそれぞれで、プロ曲の短い例を分析・再現・変形できる
* [ ] 各セクションごとの音数や緩急を意図的にコントロールできる
* [ ] Song 01 のフルアレンジが進行し、Song 02 に着手している
* [ ] 個人レッスンの指摘をパートライティング修正へ反映している
