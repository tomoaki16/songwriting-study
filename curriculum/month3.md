# Month 3｜リズムセクションとバンドアレンジ

## 月間目標
「全部の楽器を鳴らす」発想から離れ、**各瞬間で何を聴かせるのか、そのために各パートが何を担当するのか**を考えてアレンジできるようになる。

この月はドラム・ベース・ギター・その他パートの**パートライティング集中月**とする。ただしMonth 3で習得完了とはせず、Month 4〜6で実曲を通じて反復する前提で進める。

Month 1〜2で継続してきたSong 01を主教材とし、**既にある曲へ後付けで音を足すのではなく、各セクションの主役・役割・密度・音域からアレンジを再設計する。**

---

## Weekごとのテーマ

* **Week 9**: ドラム
* **Week 10**: ベース
* **Week 11**: ギター・キーボード等のその他パート
* **Week 12**: アレンジと緩急

---

## Month 3共通運用
対象パートごとに、必ず次の流れを回す。

**プロ曲2〜8小節をAnalyze → Studio Oneで再現 → 役割を言語化 → 別条件へTransform → Song 01の同等場面へApply → Before / After → 採否**

「打ち込み方を覚えた」「フレーズをコピーした」だけではクリアとしない。

---

## 学習項目

### Week 9｜ドラム
* **構成要素・技法**: Kick / Snare / Hi-hat / Ride / Crash / Tom / 基本ビート / 8ビート / 16ビート / フィル / ゴーストノート / ベロシティ
* **判断テーマ**: 何を叩くかだけでなく、どこで変化させるか、どこでは変化させないかを考える
* **Song 01 Apply**: Aメロ / Bメロ / サビ候補で最低2種類のドラム案を作り、セクション差を比較する

### Week 10｜ベース
* **役割・技法**: ルート弾き / 5度 / 3度 / 経過音 / クロマチックアプローチ / オクターブ / コードチェンジへの接続 / キックとの関係
* **重要テーマ**: 「ベースを動かす＝良い」ではなく、「ルート維持」「リズム作成」「コード接続」「メロディ的移動」を目的別に使い分ける
* **Song 01 Apply**: 同じ区間で3種類（ルート中心 / リズム重視 / 経過音あり）を作り、役割から採否を決める

### Week 11｜ギター・キーボード等
* **ギターの役割**: コード / リズム / リフ / アルペジオ / オブリガート / 単音フレーズ / テクスチャ / 空間作り
* **キーボード等の役割**: パッド / コード補強 / 単音 / リズム補助 / 音域補完 / テクスチャ
* **重要テーマ**: 常に鳴らさず、ボーカル・ベース・ドラムとの役割重複を確認する
* **Song 01 Apply**: 同じセクションに対して「コード主体 / アルペジオ・パッド主体 / 単音・オブリ主体」等を比較する

### Week 12｜アレンジと緩急
* **アレンジ手法**: Density / Register / Dynamics / 楽器の追加・削除 / セクション間コントラスト / サビへの導線 / ブレイク / ユニゾン / Call & Response
* **重要テーマ**: 盛り上げ＝足す、にしない。休符・引き算・役割交代・音域変化も使う
* **Song 01 Apply**: イントロ→A→B→サビについて、各セクションの主役・音数・音域・役割を一度文章で設計してからStudio Oneで修正する

---

## 分析課題

* **Week 9**: 既存曲のドラムをDAW上で再現し、キック / スネア / ハイハット / フィル / セクション変化を記録
* **Week 10**: ベースを「ルート維持 / リズム作成 / コード接続 / メロディ的移動」に分類
* **Week 11**: ギター・キーボード等について、鳴る / 休む / 役割を変える箇所を記録
* **Week 12**: 複数のプロ曲で各セクションの主役、入る楽器、消える楽器、音域、密度を観察

---

## 実践課題

* **Week 9**: 同じコード進行に3種類のドラムパターンを作り、1案をSong 01へ採用 / 不採用判断
* **Week 10**: 同じコード進行に3種類のベースを作り、Song 01へ適用
* **Week 11**: 同じセクションに複数のギター / キーボード役割案を作り、役割重複を整理
* **Week 12**: Song 01全体で主役・音数・音域・リズム密度を意図的に変える

---

## DTM個人レッスンの使い方

この月は個人レッスンとの相性が最も高い。

* Song 01の同じ8〜16小節について、自分で作ったドラム・ベース・ギター / キーボード案を持ち込む
* 「何となくダサい」「まとまらない」をそのまま質問せず、自分なりに原因を仮説化する
* 先生に、**どのパート / どの判断を直すと最も効果が大きいか**優先順位を確認する
* 先生の修正をそのまま採用せず、考え方を記録したうえで自分で別案を作る
* レッスン後は同じ箇所を自分で作り直し、修正前後を比較する

## 制作課題

* **Month 3制作課題（Week 12）**:
  * **Song 01をフルアレンジへ進める**
  * Song 01の中で、少なくともドラム・ベース・ギター / その他パートそれぞれ1か所は「分析→再現→変形→自作曲へ応用」の過程を経る
  * Aメロ / Bメロ / サビのセクション差を、音数・音域・役割・リズムで説明できる状態にする
  * **Song 02のコード・メロディ・構成を作り始める**

## 月末到達基準

* [ ] 各楽器を「何となく入れる」のではなく、そのパートを入れる理由を説明できる
* [ ] ドラム・ベース・ギター / その他パートそれぞれで、プロ曲の短い例を分析・再現・変形できる
* [ ] 各セクションごとの音数や緩急を意図的にコントロールできる
* [ ] Song 01がフルアレンジ段階まで進んでいる
* [ ] Song 01の主要セクションでBefore / Afterを複数残している
* [ ] Song 02に着手している
* [ ] 個人レッスンの指摘をパートライティング修正へ反映している
