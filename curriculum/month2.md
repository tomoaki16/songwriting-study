# Month 2｜コード進行とメロディ

## 月間目標
コードを並べるだけの状態から、**「どんな感情・流れを作りたいから、このコードを使う」**へ進む。
同時にコードとメロディの関係を理解し、Song 01の骨格を作る。

この月から**DTM個人レッスンを開始**し、自学習で作ったものを持ち込んで第三者の耳で検証する。

---

## Weekごとのテーマ

* **Week 5**: コード進行の設計
* **Week 6**: ノンダイアトニックコード
* **Week 7**: メロディの基礎
* **Week 8**: コードとメロディの統合

---

## 学習項目

### Week 5｜コード進行の設計
* **理論**: コード機能の復習 / 強進行 / 弱進行 / 循環 / 終止 / コードチェンジのタイミング / ベースラインとコード進行

### Week 6｜ノンダイアトニックコード
* **理論**: セカンダリードミナント / 借用和音 / modal interchangeの基本 / sus / add9 / slash chord
* *ポイント*: すべてを暗記する必要はなく、ダイアトニック外のコードが入ったときに「何かが起きている」と気づけることが重要。

### Week 7｜メロディの基礎
* **理論**: コードトーン / ノンコードトーン / 経過音 / 隣接音 / アプローチノート / モチーフ / 反復 / 変化 / 音域 / 跳躍 / 順次進行

### Week 8｜コードとメロディの統合
* **理論**: 強拍に置く音 / コードトーンとの関係 / テンション / 7th / 9th / メロディとコードの衝突 / 解決

---

## フレーズ獲得トレーニング

Month 2から、毎週少量でも**分析 → 模倣 → 変形 → 自作曲へ応用**を行う。

* Week 5〜6: 好きな曲のコード進行2〜8小節を取り出し、ベース音の動きも確認する
* Week 7〜8: 好きなメロディ2〜4小節を取り出し、コードに対する度数・リズム・反復・跳躍を確認する
* コピーしたまま終わらず、キー・コード・リズム・音域のどれかを変更して別パターンを作る
* その考え方をSong 01の一部に使ってみる

---

## 分析課題

* **Week 5**: 3曲程度のコード進行を分析。コード単体ではなく「どこで緊張し、どこで解決しているか」を見る。
* **Week 8**: 好きな曲のサビについて、メロディ音 / その瞬間のコード / コードに対する度数 を確認する。

---

## 実践課題

* **Week 5**: 同じメロディに異なるコード進行を付けて印象を比較する。
* **Week 6**: シンプルなダイアトニック進行を作り、一部をノンダイアトニックコードへ変更して比較する。
* **Week 7**: 同じコード進行に対して3種類のメロディを作る（1. コードトーン中心 / 2. 経過音を増やす / 3. 跳躍を増やす）。

---

## DTM個人レッスンの使い方

レッスン日がある週は、以下を優先して持ち込む。

* Month 1短曲またはSong 01の途中版
* 「自分では良いと思うところ」と「違和感があるところ」
* コード・メロディ・構成のどこが原因か自分なりの仮説
* 先生からは、正解を教わるだけでなく**自分の判断と先生の判断がどこで違うか**を確認する
* レッスン後は最低1か所を修正し、Before / Afterで聴き比べる

## 制作課題

* **Month 2制作課題（Week 8）**:
  * **Song 01の骨格を作る**

  * 一度は個人レッスンまたは自己分析でフィードバックを得て、修正版を残す
