# Month 1 Week 4｜リズム・曲構成・Month 1総合

## Week 4の位置づけ
Week 1〜3で、音程・スケール・コード構成・7th・転回形・Degree・Function・Cadenceまでを、ギター / Studio One / Song 01へ接続して学習した。

Week 4では新しい和声理論を増やすのではなく、**音楽が時間の中でどう配置されるか**へ視点を広げる。

扱う中心は、
- 音価 / 拍 / 小節 / 拍子 / BPM
- 8分・16分 / 休符 / 表拍・裏拍 / シンコペーション
- Intro / Verse / Pre-Chorus / Chorus / Interlude / Bridge / Outro
- セクションごとの小節数・反復・入り / 抜け・密度

Month 3のドラムパートライティングは先取りしない。Week 4では、**リズムを読める・数えられる・比較できる・Song 01の構成を時間軸で設計できる**ことを目標とする。

## 進度設計
- Day 1〜Day 6＋Reviewの7学習Issue
- Day番号は実日ではない
- Week 1〜3と同様、理解確認を通過したら同一実日に複数Dayへ進んでよい
- 既知の拍 / BPM等は短い確認で通過し、Analyze / Practice / Song Applyへ時間を使う
- 各実日の終了時は、最後に更新する学習IssueまたはStudy Metrics Issueへ `学習日: YYYY-MM-DD` / `日次学習時間: XX分` を1回だけ記録する

## Song 01の最新前提｜2026-08-26
- Status: Structuring
- Key: E majorを基準
- 現素材：ギターのコード進行＋ベースフレーズ
- AメロではB7 / Am7の対比を利用
- Aメロ末：…E → G#m → A7 → Am7
- Bメロ1周目：F#m7 → A → C#m7 → D#dim
- Bメロ2周目：F#m7 → G#m7 → A → B
- サビ頭候補：E
- Bメロ1周目は期待を外しながら浮遊、2周目はII→III→IV→Vとサビへ素直に前進、B→Eで着地する設計
- 曲全体 / メロディ / ドラム / その他パートは未完成

## Week 4到達基準
- [ ] 全音符〜16分音符、対応する基本休符を拍数で説明できる
- [ ] 4/4拍子で拍と小節を数え、8分 / 16分グリッドをStudio One上で扱える
- [ ] BPMが速さ、音価・休符がリズムの配置を決めることを区別できる
- [ ] 表拍 / 裏拍 / シンコペーションを実音で聞き分け、簡単なパターンを作れる
- [ ] 既存曲2〜3曲についてセクション名 / 小節数 / 反復 / 楽器の入り抜きを観察できる
- [ ] 同じコード進行でもリズム / 休符 / 小節配置で印象が変わることをBefore / Afterで説明できる
- [ ] Song 01の現状をStudio Oneのタイムライン上で、セクション / 小節数 / コード / 主な入り抜きとして整理できる
- [ ] Song 01のA→B→サビ導線について、和声だけでなく「小節 / リズム / 区切り」の観点から1案設計できる
- [ ] Month 1の学びをSong 01の最低2か所へ適用済みと確認し、次月へ持ち越す課題を言語化できる

## Day構成

2. Day 2｜8分・16分・休符｜同じコードでリズムを変える
3. Day 3｜表拍・裏拍・シンコペーション｜予測とノリを比較
4. Day 4｜既存曲2〜3曲の構成分析｜小節数・反復・入り抜き
5. Day 5｜Song 01タイムライン設計｜A→B→サビを小節で整理

7. Review｜Month 1総合確認＋Month 2への課題設定

## Day 1｜音価・拍・小節・BPM
- p.10 / 14 / 16を短くLearn
- 全 / 2分 / 4分 / 8分 / 16分の長さを4/4上で説明
- Studio Oneのグリッドと小節表示を使い、1〜4小節の位置を確認
- BPMだけを変えた場合と、音価だけを変えた場合を比較

## Day 2｜8分・16分・休符
- 同じ1〜2コードを、4分中心 / 8分中心 / 16分を含む形で比較
- 休符を入れた版を作り、音数を増やす以外でノリ・余白が変わることを確認
- ギターのバッキングとStudio One双方で比較

## Day 3｜表拍・裏拍・シンコペーション
- 表拍 / 裏拍をカウントできる
- 同じ音高・コードで発音位置だけを変えて比較
- シンコペーションを「難しいリズム」ではなく、予想される強拍位置をずらす / またぐ効果として実音確認
- Song 01へ入れる場合は局所的に1案だけ試し、曲調に合わなければ不採用でよい

## Day 4｜既存曲構成分析
2〜3曲を対象に、最低限以下を記録する。
- BPM（確認できる範囲）
- Intro / A(Verse) / B(Pre-Chorus) / Chorus等
- 各セクションの小節数
- 同じ進行 / モチーフの反復回数
- 楽器が増える / 減る / 休む箇所
- 「サビになった」と感じる直前に何が変わるか

Month 3の詳細なドラム / ベース採譜はしない。ここでは**構成と密度の変化**を見る。

## Day 5｜Song 01タイムライン
- 現在あるAメロ / Bメロ / サビ頭候補をStudio Oneの小節単位で並べる
- 各コードが何拍 / 何小節続くかを明示
- Aメロ何周、Bメロ何周かを構造として記録
- A→B、B→サビで「コード以外に何を変えるか」を候補化
- まだ存在しないIntro / サビ全体等は無理に完成させず、空欄 / TODOとして可視化

## Day 6｜Month 1総合Apply
- Week 1〜3の理論とWeek 4のリズム / 構成を一度Song 01上で統合
- 30〜60秒以上を基準音源として書き出せる状態を目指す
- Before / Afterは最低1つ
- 自己評価を Composition / Arrangement / Performance / Sound / Mix の順で切り分ける
- Month 1ではMix改善を主課題にしない

## Review｜Month 1総合
- 音程 / スケール / コード構成 / Degree / Function / Cadence / リズム / 曲構成を横断確認
- Song 01で「理論を使って意図的に決めた箇所」を最低2つ説明
- 分からない / 未完成な部分を明示
- Month 2で最優先する課題を3つ以内に絞る

## Month 2への橋渡し
Month 2 Week 5からは、代理コード・ドミナントモーション・長短調・五度圏等へ進む。

Week 4ではノンダイアトニックの詳細説明を先取りしない。Song 01のA7 / Am7等は「現時点でダイアトニック外と認識できる」状態を維持し、Week 6で正式に分析する。
