# 作曲自己学習｜6か月プラン

> 1日約1時間、理論・分析・実制作を往復しながら、6か月後までにオリジナル曲を5曲完成させる。

## 学習条件とゴール

- 期間: 6か月（約26週間）
- 学習時間: 1日約1時間を目安に、週5〜6日
- 制作環境: Studio One / ギター
- 優先する力: 作曲・編曲・DTM・ミックスの基礎と「完成させる力」
- 最終成果: オリジナル曲 5曲を完成（書き出し・振り返りまで）

## 今週

**Week 1｜音程・コード・ダイアトニックの基礎**

- GitHub Issue のチェックリストに沿って進める
- 学ぶ → プロ曲を分析する → 短く試す → 自作へ使う → 振り返る、を毎週繰り返す
- 週末に Issue の「週末レビュー」を更新する

## 運用ルール

1. **週の開始**: 1週間につき Issue を1件作る（26週で約26件）。
2. **毎日の学習**: Issue のチェックを進め、気づきは一言でも残す。
3. **週末**: Issue の「週末レビュー」を更新し、未完了項目は翌週へ持ち越す。
4. **曲を進めたとき**: 該当する `songs/song0N.md` のチェックを更新し、README の「現在地」と「次の一歩」を更新する。
5. **負担を増やさない**: 記録は箇条書きで十分。空白の週を埋め直すより、次の週を始める。

週次レビューの書式: [weekly-review/README.md](weekly-review/README.md)
