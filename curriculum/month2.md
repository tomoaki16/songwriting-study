# Month 2｜コード進行・メロディ＋Song 01骨格

## 月間目標
Month 1の基礎から進み、**自分の曲で何が起きているかを理論的に分析できる土台**を作る。同時に、理論を後付けの説明だけにせず、欲しい響きや流れを先に考えてコード・メロディを選ぶ練習を始める。

Month 1から使っている既存自作曲をSong 01として継続し、現在のイントロ〜Bメロを分析・修正しながら、**サビを含む曲全体の骨格**まで進める。

DTM個人レッスンは、Month 1で定めた開始条件を満たした時点で開始する。

> テキスト全60項目中45項目（75%）を半年の標準範囲とする。A/B分類は `textbook-reference.md` を参照。

---

## Weekごとのテーマ
- **Week 5**: 長調・短調の機能とコード進行を分析する
- **Week 6**: ノンダイアトニックコードを分析し、狙って使う
- **Week 7**: メロディを理論と耳の両面から分析する
- **Week 8**: コード・メロディ・テンションを統合し、Song 01全体の骨格を作る

---

## Month 2共通運用
毎週、次の流れを原則とする。

**Learn → 既存曲Analyze → Studio Oneで再現 → Song 01の4〜16小節へApply → Before / After → 採否 → Review**

理論課題を別ファイルで完結させず、必ずSong 01へ最低1か所つなげる。

## 自作曲の理論分析
Song 01について最低限以下を記録する。
1. Key / Major・Minor / 使用スケール
2. セクションごとのコード進行
3. Degree
4. コード機能と緊張・解決
5. ダイアトニック外コードとその説明
6. ベース音 / 転回形 / 分数コード
7. 主要メロディ音のコードに対する度数
8. 7th / 9th / add9等のコードカラー・衝突・解決
9. 偶然できた箇所 / 理論を使って狙った箇所

説明できない箇所があってもよい。**説明できない箇所を特定できること自体を学習成果**とする。

## DTM個人レッスン
初回はSong 01の現状版を持ち込む。

準備するもの：
- Song 01の書き出し音源
- 自分で良いと思う点 2〜3個
- 違和感 2〜3個
- 原因仮説（Composition / Arrangement / Performance / Mix）
- 半年後に全工程を自力で進めたいという目標

先生には、**現状で最も弱い能力・改善効果の高い課題・自分の判断とのズレ**を優先して確認する。

レッスン後は最低1か所を自分で修正しBefore / Afterを残す。
