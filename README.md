# 6か月作曲学習計画

> 1日約1時間。基礎理論を体系的に学びながら、**既存曲の分析 → 模倣・変形 → ギターで実音確認 → Studio Oneで再現・比較 → 自作曲への応用 → 個人レッスンで検証 → 修正**を繰り返し、6か月間でオリジナル曲5曲を完成させる。

---

## 0. このカリキュラムの目的

半年間、作曲を基礎から体系的に学習し、最終的に**オリジナル曲5曲を完成させる**。

単に5曲を作ることが目的ではない。

**Learn → Analyze → Imitate / Transform → Practice → Apply → Feedback → Review**

を繰り返し、コード・メロディだけでなく、**ドラム、ベース、ギター、キーボード等の各パートを自分で考え、1曲全体を設計・アレンジ・録音・ミックス・完成できる力**を身につける。

### 学習条件

* **期間**: 6か月
* **自学習時間**: 1日約1時間（週約7時間を上限の目安とする）
* **DAW**: Studio One
* **ギター**: 演奏可能
* **ベース**: 録音可能。演奏技術そのものより作曲・編曲上のパート設計を優先
* **ドラム**: 主に打ち込み
* **現在地の制作物**: Song 01は現在、**ギターのコード進行＋ベースフレーズのみ**。Aメロ〜Bメロ周辺を中心に理論学習のApplyを進めているが、曲全体・メロディ・ドラム等は未完成
* **DTM個人レッスン**: **Song 01をまず自力で一通り完成させてから開始する**。未完成段階で先生に設計を委ねず、自分で一度最後まで作った成果物を持ち込み、自分の判断とプロの判断の差を検証する
* **最終成果**: オリジナル曲5曲完成
* **標準教材**: 現在使用中の作曲テキスト。ページ対応は [`curriculum/textbook-reference.md`](curriculum/textbook-reference.md) に一元管理する

## 1. 半年間を通して続ける5本柱

### ① 理論・基礎理解
音程、スケール、コード、機能、リズム、メロディなどを体系的に学ぶ。暗記で終わらず、**既存曲で見つけられる → Studio Oneで確認できる → 自分の曲で使える**までを習得とする。

### ② ギターとDAWの二重確認
Month 1から理論学習とStudio Oneを分離しない。

原則として各学習単位で、

**理論 → ギターで鳴らす → Studio Oneで再現 / 比較 → 自作曲4〜16小節で試す → Before / After → 採否を自分で決める**

までを一つのサイクルとする。

### ③ フレーズ獲得トレーニング
Month 1後半からMonth 6まで継続する。

1. 好きなプロ曲から2〜8小節程度を選ぶ
2. 対象パートを耳・DAW・譜面等で確認する
3. リズム、音程、コードに対する度数、セクション内の役割を分析する
4. Studio Oneでできる範囲で再現する
5. キー、コード、リズム、音域等を変えて変形する
6. Song 01〜05へ考え方を応用する

### ④ 5曲の実制作
知識習得後に制作するのではなく、**Month 1からSong 01を教材として並走**させる。まずSong 01を自力で一通り完成させ、その後の個人レッスンで弱点と判断差を検証する。

### ⑤ DTM個人レッスン
開始条件は**Song 01を自力で一通り完成させること**。

完成版を持ち込み、知識を増やすより、**自分の判断とプロの判断の差、改善優先順位、独学では判断しにくいアレンジ・音色・録音・MIX**を確認する。

## 4. 個人レッスンへの持ち込み優先順位

Song 01を一通り完成させたうえで、以下の順に自分の判断との差を確認する。

1. **Composition**: コード、メロディ、構成
2. **Arrangement / Part Writing**: ドラム、ベース、ギター、キーボード、役割分担、音数、展開
3. **Performance / Sound**: 演奏、打ち込み、音色、録音
4. **Mix**: Volume、Pan、EQ、Compression、空間系

レッスンの価値は「先生に直してもらう」ことではなく、**自分の判断とプロの判断の差を言語化し、次回は自力で判断できる範囲を増やすこと**に置く。

## 5. 重要な運用ルール

1. **計画を絶対視しない**: 到達基準を満たしたら予定日数より早く進んでよい。
2. **理論とDAWを分離しない**: Month 1から毎週Studio Oneを使う。
3. **毎週Song 01または制作中Songへ小さくApplyする**: 原則4〜16小節でよい。
4. **Before / Afterを残す**: 採用だけでなく不採用も判断記録として価値を持つ。
5. **各楽器はMonth 3で「終了」にしない**: Month 4〜6でも書き直し続ける。
6. **「理解した」の基準を厳しくする**: 説明 → 発見 → 再現 → 変形 → 自作曲で使用。
7. **個人レッスンはSong 01を一通り完成させてから開始し、指摘は必ず自分で再実装する**。
8. **ミックスでアレンジの失敗を隠さない**。
9. **5曲完成を最優先する**。
10. **進捗管理に時間を使いすぎない**。

## 最終ゴール

半年終了時点で、

* なぜこのコードなのか
* なぜこのメロディ音なのか
* なぜここでベースを動かすのか
* なぜこのドラムフィルなのか
* なぜここではギター / キーボードを弾かないのか
* なぜこのサビが盛り上がるのか
* なぜこの音源がショボく聞こえるのか

を自分で考え、必要ならリファレンスや個人レッスンから判断材料を得ながら、**作曲 → パートライティング → アレンジ → 録音 → ミックス → 完成**まで進められること。

成果物として**完成したオリジナル曲5曲**を残す。
