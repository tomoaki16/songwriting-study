# Month 1 Week 3｜コード機能・ディグリー・ケーデンス＋Song 01分析

Week 1〜2で、音程・スケール・コード構成・7th・転回形・ボイシングを学び、Song 01では同じコード進行でもベース配置によって穏やかさや期待感を設計できるところまで到達した。

## Day 1｜ディグリーとコード機能
- E major等でI〜VIIを自力導出
- コードネームとディグリーを相互変換
- T / S / Dの基本概念をLearn
- ギターで代表コードを鳴らし「安定 / 移動 / 緊張」を自分の言葉で記録

## Day 2｜機能を実音で比較
- 同じKeyでT→S→D→Tを作る
- I / IV / Vを中心に、iii / vi / ii / viiの聴感も比較
- Studio Oneで同じテンポ・音域条件にそろえて比較
- 「コード名ではなく役割で選ぶ」練習をする

## Day 3｜ケーデンス
- テキストp.58をLearn
- 代表的な終止パターンをギター / Studio Oneで比較
- 強い帰着 / 柔らかい帰着 / 終わらない感じ等を聴感で記録
- Week 1で体験したB→Eの強い帰着を理論と接続

## Day 4｜機能を使って変形
- 既存の短い進行をDegree / Functionへ変換
- 狙いを先に決める（例：穏やか、期待、強い解決）
- 機能を維持しながらコードを変える、または機能の流れを変えて聴感比較
- Before / Afterを保存

## Day 5｜既存曲分析
- 好きな曲1曲を選ぶ
- Key / コード / Degree / Function / Cadenceを分析
- 「なぜここで展開を感じるか」「なぜ戻った感じがするか」を最低2箇所説明
- 必要ならギター / Studio Oneで再現

## Day 6｜Song 01 Apply
- Song 01のAメロ〜Bメロ接続を分析
- E majorを基準に、ダイアトニック / ノンダイアトニックを区別
- Bメロ候補 F#m7 → B7 → G#m7 → C#m7 をDegree / Functionで分析
- A7 / Am7等、Key E外のコードは「機能が説明できない＝誤り」とせず、現段階で分かる範囲とWeek 3以降へ持ち越す範囲を区別する
- 必要なら1箇所だけ機能を意識して変更しBefore / After比較
- コード進行を変えない方が良い場合は、不変更の理由も採否判断として記録

## Review
- ランダムなコード→Degree
- Degree→Key内コード
- T / S / Dの説明
- 実音から安定 / 移動 / 緊張 / 解決を言語化
- ケーデンス判定
- 既存曲分析結果を説明
- Song 01の1区間をDegree / Functionで説明

## Week 4への橋渡し
Week 3でコード進行の時間的な役割を理解した後、Week 4ではリズム・小節・曲構成へ進む。Song 01はまだ完成を要求せず、ギターコード＋ベースフレーズを基礎に、曲全体を作るために不足している構成・リズム要素を整理する。
