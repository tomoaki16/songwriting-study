# Month 5｜録音・サウンド・ミックス基礎

## 月間目標
良い曲・良いアレンジを、最終的に**聴ける音源へ変換する基礎能力**を身につける。

ミックスの高度なテクニックより、**録音・音選び・アレンジ段階で問題を作らないこと**を優先する。音が悪いときに、MIXだけでなく「フレーズ・音域・役割分担」まで戻って原因を切り分けられる状態を目指す。

---

## Weekごとのテーマ

* **Week 17**: 録音
* **Week 18**: 音作り
* **Week 19**: ミックス基礎
* **Week 20**: リファレンス比較＋アレンジ再点検

---

## 学習項目

### Week 17｜録音
* **基礎知識**: Input Gain / Headroom / Clipping / DI / ギター録音 / ボーカル録音 / テイク管理 / ダブルトラック / タイミング / ピッチ
* **重要テーマ**: MIX前に演奏・タイミング・録り音の問題を減らす

### Week 18｜音作り
* **シグナルフロー**: アンプ / Gain / EQ / 歪み / Compression / Reverb / Delay
* *重要点*: プラグインを増やすより「元音 → アンプ → EQ → 空間」の基本フローを理解する
* **追加視点**: 音色単体ではなく、他パートと同時に鳴ったときの帯域・役割で判断する

### Week 19｜ミックス基礎
* **優先順位**: 1. Volume → 2. Pan → 3. EQ → 4. Compression → 5. Reverb / Delay
* *重要テーマ*: 「浮いている音」をエフェクトだけで直そうとせず、まず演奏 / 音色 / 音域 / アレンジ / 音量を疑う

### Week 20｜リファレンス比較＋アレンジ再点検
* **比較観点**: Vocal level / Low end / Guitar level / Stereo width / Dynamics / Reverb / 全体密度
* **診断順序**: Composition → Arrangement / Part Writing → Performance / Sound → Mix の順に原因候補を確認する

---

## フレーズ獲得トレーニング

Month 5でも継続する。ただし目的は「新しい技を増やす」より、**録音・ミックスして初めて見えたアレンジ問題を直すこと**。

例:
* ギターがボーカルとぶつかる → プロ曲で歌中のギター音域・休符・定位を分析
* ベースとキックが重い → リズムの噛み合わせと音価を分析
* サビが広がらない → パート追加ではなく音域・ダブル・休符・リズム密度を分析

必ず「プラグインで直す案」と「アレンジで直す案」を比較してから判断する。

---

## 分析課題

* **Week 17**: 自分の録音で、演奏・タイミング・音色・録音レベルの問題を分けて記録する
* **Week 18**: リファレンスのギター/ベース等について、単体音ではなく曲中での役割と帯域を観察する
* **Week 20**: プロ曲と自作曲を聴き比べ、ボーカルレベル、ローエンド、ステレオ感、全体密度を評価する

---

## 実践課題

* **Week 17**: 同じギターフレーズを条件を変えて録音し比較する
* **Week 18**: 同一フレーズで音色を複数作り、ソロではなくアンサンブル内で選ぶ
* **Week 19**: Volume / Panだけの状態と、EQ・Comp・空間系を加えた状態を比較する
* **Week 20**: 自作曲の問題点を最低3件、「アレンジで直す / 録音で直す / MIXで直す」に分類して修正する

---

## DTM個人レッスンの使い方

この月は**制作とミックスの境界を学ぶ場**として使う。

* Song 02またはSong 03のミックス前後を持ち込む
* 「この音が浮く原因はEQか、演奏か、フレーズか、音色か」を自分なりに仮説化する
* 先生に、どの工程まで戻るべき問題かを確認する
* 可能なら先生の修正を見た後、自分でも別案を作る
* Before / Afterと、何を変えたかを記録する
