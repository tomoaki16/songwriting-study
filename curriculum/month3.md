# Month 3｜リズムセクションとバンドアレンジ

## 月間目標
「全部の楽器を鳴らす」発想から離れ、**各瞬間で何を聴かせるのか、そのために各パートが何を担当するのか**を考えてアレンジできるようになる。
ベース・ドラム・ギター・楽器の役割・音数・緩急を重点的に扱う。

---

## Weekごとのテーマ

* **Week 9**: ドラム
* **Week 10**: ベース
* **Week 11**: ギター・その他のパート
* **Week 12**: アレンジと緩急

---

## 学習項目

### Week 9｜ドラム
* **構成要素・技法**: Kick / Snare / Hi-hat / Ride / Crash / Tom / 基本ビート / 8ビート / 16ビート / フィル / ゴーストノート / ベロシティ

### Week 10｜ベース
* **役割・技法**: ルート弾き / 5度 / 3度 / 経過音 / クロマチックアプローチ / オクターブ / コードチェンジへの接続 / キックとの関係
* *重要テーマ*: 「ベースを動かす＝良い」ではなく、「ルート維持」「リズム作成」「コード接続」「メロディ的移動」を目的別に使い分ける。

### Week 11｜ギター・その他のパート
* **ギターの役割**: コード / リズム / リフ / アルペジオ / オブリガート / 単音フレーズ / テクスチャ / 空間作り
* *重要テーマ*: ギターを常にストロークし続けず、ボーカル・ベース・ドラムとの役割重複を確認する。

### Week 12｜アレンジと緩急
* **アレンジ手法**: Density（音数・密度） / Register（音域） / Dynamics / 楽器の追加・削除 / セクション間のコントラスト / サビへの導線 / ブレイク / ユニゾン / Call & Response

---

## 分析課題

* **Week 9**: 既存曲のドラム（キック位置、スネア位置、ハイハット、フィル、セクションによる変化）をDAW上で再現する。
* **Week 12**: 複数のプロ曲について各セクションで「主役は誰か」を記録し、入っている楽器・消える楽器・音域・リズム密度を観察する。

---

## 実践課題

* **Week 9**: 同じコード進行に3種類のドラムパターンを作る。
* **Week 10**: 同じコード進行に3種類のベース（1. ルート中心 / 2. リズム重視 / 3. 経過音あり）を作る。
* **Week 11**: ギターのストローク過多を避け、役割分担を整理する。

---

## 制作課題

* **Month 3制作課題（Week 12）**: 
  * **Song 01をフルアレンジへ進める。**
  * 同時に**Song 02のコード・メロディ・構成を作り始める。**

---

## 月末到達基準

* [ ] 各楽器を「何となく入れる」のではなく、そのパートを入れる理由を説明できる
* [ ] 各セクションごとの音数や緩急（コントラスト）を意図的にコントロールできる
* [ ] Song 01 のフルアレンジが進行し、Song 02 の着手を開始している
