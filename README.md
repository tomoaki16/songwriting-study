# 6か月作曲学習計画

> 1日約1時間。基礎理論を体系的に学びながら、**既存曲のフレーズ分析 → 模倣 → 変形 → 自作曲への応用 → 個人レッスンでの外部フィードバック → 修正**を繰り返し、6か月間でオリジナル曲5曲を完成させる。

---

## 0. このカリキュラムの目的

半年間、作曲を基礎から体系的に学習し、最終的に**オリジナル曲5曲を完成させる**。

単に5曲を作ることが目的ではない。

**基礎理解（Learn） → 楽曲・フレーズ分析（Analyze） → 模倣・変形（Imitate / Transform） → 小さな実践（Practice） → 自作曲への応用（Apply） → 個人レッスンで検証（Feedback） → 修正・振り返り（Review）**

を繰り返し、コード・メロディだけでなく、**ドラム、ベース、ギターを含む各パートを自分で考え、1曲全体を設計・アレンジ・録音・完成できる力**を身につける。

### 学習条件

* **期間**: 6か月
* **自学習時間**: 1日約1時間（週約7時間を上限の目安とする）
* **DAW**: Studio One
* **ギター**: 演奏可能
* **ベース**: 録音可能。演奏技術そのものより作曲・編曲上のパート設計を優先
* **ドラム**: 主に打ち込み
* **DTM個人レッスン**: Month 1終了後から並行して受講。自学習とは別の知識を増やす場ではなく、制作物を持ち込み、第三者の耳・プロの視点で課題を発見し修正する場として使う
* **最終成果**: オリジナル曲5曲完成
* **標準教材**: 現在使用中の作曲テキスト。学習内容とページの対応は [`curriculum/textbook-reference.md`](curriculum/textbook-reference.md) に一元管理する

## 1. 半年間を通して続ける4本柱

### ① 理論・基礎理解
音程、スケール、コード、機能、リズム、メロディなどを体系的に学ぶ。理論は暗記で終わらず、**既存曲で見つけられる → 自分の曲で使える**までを習得とする。

### ② フレーズ獲得トレーニング
Month 1後半からMonth 6まで継続する。

1. 好きなプロ曲から2〜8小節程度を選ぶ
2. ドラム / ベース / ギター / メロディのうち、その週の対象パートを耳・DAW・譜面等で確認する
3. リズム、音程、コードに対する度数、セクション内の役割を分析する
4. できる範囲で再現する
5. キー、コード、リズムの一部を変えて別フレーズへ変形する
6. 自作曲の一部へ考え方を応用する

目的はコピー曲を増やすことではなく、**「こういう場面ならこう動ける」というフレーズ語彙と判断力を増やすこと**。

### ③ 5曲の実制作
知識習得後に制作するのではなく、Month 2から制作を並走させる。各Songを教材として、前曲で見つかった弱点を次曲で改善する。

### ④ DTM個人レッスン
Month 1終了後から開始する。レッスン日がある週は、原則として以下を1サイクルにする。

**事前**: 自作曲・課題箇所・質問を準備  
**レッスン**: 自分では判断できない問題、プロとの判断差、改善優先順位を確認  
**直後**: 指摘事項をGitHub Issueへ記録  
**次回まで**: 自分で修正し、Before / Afterを比較

レッスンでは特に、**各楽器のフレーズ、アンサンブル、展開、音色、録音、ミックスのうち「独学では正解判断が難しいもの」**を優先して確認する。

## 4. 個人レッスンへの持ち込み優先順位

毎回すべてを質問しない。制作物を聴いたうえで、改善効果の高いものから確認する。

1. **Composition**: コード、メロディ、構成そのものに問題があるか
2. **Arrangement / Part Writing**: ドラム、ベース、ギターのフレーズや役割分担、音数、展開に問題があるか
3. **Performance / Sound**: 演奏、打ち込み、音色、録音に問題があるか
4. **Mix**: Volume、Pan、EQ、Compression、空間系に問題があるか

レッスンの価値は「先生に直してもらう」ことではなく、**自分の判断とプロの判断の差を言語化し、次回は自力で判断できる範囲を増やすこと**に置く。

## 5. 重要な運用ルール

1. **計画を絶対視しない**: 理解度や制作進捗によって週次計画を変更してよい。月間到達目標を優先する。
2. **毎週必ず音を作る**: 理論だけで終わらせない。
3. **毎週少量でもフレーズを採取する**: 分析だけで終わらず、模倣 → 変形 → 自作曲への応用まで行う。
4. **各楽器はMonth 3で「終了」にしない**: Month 4〜6でも制作曲を通じてドラム・ベース・ギターを書き直し続ける。
5. **「理解した」の基準を厳しくする**: 説明できる → 既存曲で見つけられる → 模倣できる → 条件を変えて作れる → 自作曲で使える。
6. **個人レッスンの指摘を必ず実装する**: 聞いて終わりにせず、Before / Afterを作る。
7. **ミックスでアレンジの失敗を隠さない**: 音が悪いときは、演奏・音色・音域・フレーズ・役割分担まで戻って確認する。
8. **5曲完成を最優先する**: ノートだけ残して未完成にしない。完成 → 評価 → 次曲で改善の回転を優先する。
9. **進捗管理に時間を使いすぎない**: GitHub記録はChatGPTを活用し、実際の学習・制作時間を確保する。
10. **標準教材とIssueを対応させる**: 日別Issueには必要な教材ページを記載する。

## 最終ゴール

半年終了時点で、

* なぜこのコードなのか
* なぜこのメロディ音なのか
* なぜここでベースを動かすのか
* なぜこのドラムフィルなのか
* なぜここではギターを弾かないのか
* なぜこのサビが盛り上がるのか
* なぜこの音源がショボく聞こえるのか

を自分で考え、必要ならリファレンスや個人レッスンから判断材料を得ながら、**作曲 → パートライティング → アレンジ → 録音 → ミックス → 完成**まで進められること。

成果物として**完成したオリジナル曲5曲**を残す。
