# Month 6｜5曲完成と総合ブラッシュアップ

## 月間目標
新しい知識を大量に増やす月ではない。
これまで学んだことを使い、**5曲を完成させる。**

同時に、コード・メロディ・構成だけでなく、ドラム・ベース・ギターのパートライティング、録音、音色、ミックスまでを自分で判断し、必要に応じてリファレンス分析や個人レッスンへ戻れる状態を目指す。

---

## Weekごとのテーマ

* **Week 21**: Song 03完成
* **Week 22**: Song 04制作
* **Week 23**: Song 04完成・Song 05制作
* **Week 24**: Song 05完成
* **Week 25**: 5曲ブラッシュアップ
* **Week 26**: 最終完成・半年間レビュー

---

## 学習項目・課題

### Week 21｜Song 03完成
* Song 03を完成させる
* コード / メロディ / リズム / ドラム / ベース / ギター / 演奏 / 録音 / ミックスを自己評価する
* Song 01〜03を比較し、改善した点とまだ弱い点を確認する

### Week 22｜Song 04制作
* 過去3曲の課題を制作前に3〜5項目へ絞る
* 「音を入れすぎない」「主役を決める」「セクション差を作る」「ベースを目的なく動かさない」「無意味なドラムフィルを入れない」など、過去に得た判断基準を最初から反映する
* 詰まった箇所だけリファレンスへ戻り、短いフレーズを分析→変形→応用する

### Week 23｜Song 04完成・Song 05制作
* Song 04を完成させる
* Song 05のフル制作を開始する
* Song 05では、半年間で学んだ判断プロセスをできる限り自力で回す

### Week 24｜Song 05完成
* Song 05を完成させ、5曲すべてを一旦「完成」状態にする
* 100点を狙わず、5曲書き出すことを優先する

### Week 25｜5曲ブラッシュアップ
5曲を連続して聴き、以下の4観点で整理する。

* **Composition**: コード / メロディ / 構成
* **Arrangement / Part Writing**: ドラム / ベース / ギター / 音数 / 音域 / 緩急 / 主役
* **Performance / Sound**: 演奏 / 打ち込み / 録音 / 音色
* **Mix**: Volume / Pan / EQ / Compression / 空間 / 全体バランス

修正効果の高いものだけ直す。

### Week 26｜最終完成・半年間レビュー
* 5曲のFinal Versionを書き出す
* できるようになったこと
* まだ弱いこと
* Month 1短曲とSong 05の比較
* 個人レッスンで何を自力判断できるようになったか
* 次の6か月で伸ばす能力を3〜5項目に絞る

---

## フレーズ獲得トレーニング

Month 6では独立課題として大量に行わない。
制作中に「ここをどうすればよいか分からない」という具体的な課題が出たときだけ、リファレンスから必要な2〜8小節を探し、分析 → 変形 → 自作曲への応用を行う。

狙いは、**知識が足りないから止まるのではなく、必要なときに自分で材料を取りに行ける制作習慣を定着させること**。

---

## DTM個人レッスンの使い方

Month 6は「先生に完成させてもらう」のではなく、**最終レビューと判断精度の確認**に使う。

* 自分で優先順位をつけてから曲を持ち込む
* 先生には「どこを直すべきか」だけでなく、自分の改善案が妥当か確認する
* 指摘事項をすべて採用せず、自分の曲の意図と照らして採否を判断する
* 最終的には、先生なしでも次の曲を進めるための判断基準を持ち帰る
