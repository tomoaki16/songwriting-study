# 週次レビュー

各週のIssue末尾に、次の書式を貼り付けて更新する。レビュー専用ファイルは、月末に振り返りを残したくなったときだけ追加する。

```markdown
## 週末レビュー

- 理解できたこと:
- まだ曖昧なこと:
- ギターで分かったこと:
- Studio Oneで分かったこと:
- 既存曲から持ち帰ったこと:
- Song 01〜05へ反映したこと:
- Before / Afterで変わったこと:
- 採用しなかった変更と理由:
- 次週へ持ち越すこと:
```

## Issue の最小テンプレート

1. その週のテーマをタイトルにする
2. 「基礎知識」「楽曲分析」「ギター / Studio One実践」「自作曲への応用」「振り返り」を置く
3. Month 1以降、可能な範囲で制作中Songの4〜16小節へ学びを適用する
4. Before / Afterを比較し、採用だけでなく不採用理由も記録する
5. 未完了は翌週のIssueに移し、古いIssueは学習ログとして残す
