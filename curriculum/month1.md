# Month 1｜音楽の仕組みと作曲の基礎

## 月間目標
音・スケール・コード・キー・コード機能・リズム・曲構成について、今後の作曲学習に必要な基礎を体系的に理解する。
暗記だけではなく、**「なぜこのコードが使えるのか」「今鳴っている音が何なのか」**を説明できる状態を目指す。

Month 1終了時には30〜60秒の短曲を作り、**Month 2から始めるDTM個人レッスンへ持ち込める「現在地の基準音源」**を残す。

> 標準教材のページ対応は [`textbook-reference.md`](textbook-reference.md) を参照。日別Issue作成時は、このファイルと教材対応表の両方を確認する。

---

## 実績に応じた進度調整｜2026-08-19
Week 1は当初7日想定だった内容を**実学習4日間**で完了した。確認テスト、ギター実演、既存曲分析、8小節ミニ実践まで実施しており、単純な読み飛ばしではなく到達基準を満たしたうえでの前倒しと判断する。

今後は以下の方針で進める。

1. **7日分を必ず7日かける運用にはしない**。到達テストを通過したら次へ進む。
2. ただし、余った時間を新規理論の詰め込みだけには使わず、**Analyze / Practice / Apply** を増やす。
3. Month 1の月末到達基準と30〜60秒短曲の制作課題は変更しない。
4. Week 1で三和音ダイアトニックコード、maj7 / 7 / m7、終止感、キー外コードの存在まで一部先取りしたため、Week 2は重複説明を短くし、**コード語彙の体系化・四和音・転回形・ボイシング・実曲での配置確認**へ時間を振る。
5. Week 3のコード機能は前倒し可能だが、正式学習はWeek 3の到達課題として残す。Week 2では「B→Eの方がA→Eより強く帰る」など、耳で感じた現象への橋渡しに留める。

### Week 1からの持ち越し
- コード進行からキーを素早く特定する力
- 「落ち着かせたい / 緊張させたい」など、狙った効果からコード進行を選ぶ力
- Tonic / Subdominant / Dominant の正式理解
- m7♭5、転回形、コードネーム⇄構成音の即応力

### Week 2｜コードの基本
* **理論**: 三和音（メジャー, マイナー, diminished。augは存在確認） / ルート・3度・5度 / コード構成音 / コードネームの法則 / 転回形
* **7thコード**: maj7 / 7 / m7 / m7♭5。メジャースケールから四和音ダイアトニックコードを導出する
* **配置・聴感**: 同じコードでもルートポジション / 転回形 / ギター上のポジションにより響きとつながりが変わることを実音で比較する
* **実績反映**: major / minor / dim、maj7 / 7 / m7 はWeek 1で一部先取り済み。Week 2では復習を短くし、**m7♭5、四和音の体系、転回形、コードネーム⇄構成音、実曲のボイシング観察**を主対象にする
* **使用テキスト対応**:

## 分析課題

* **Week 1**: 好きな曲のキーを1曲調べる【完了：スピッツ「ロビンソン」】
* **Week 2**: 同じコードでもルート・3度・5度・7度の配置によって響きがどう変わるか確認する。既存曲2〜8小節から三和音 / 7th / 転回形またはベース配置を観察し、1例を自分で変形する
* **Week 3**: 好きな曲を1曲選び、キー・コード・ディグリー・コード機能を書き出す
* **Week 4**: 2〜3曲について、セクション / 小節数 / コード進行 / 楽器の増減 を記録する

---

## 実践課題

* **Week 1**: CメジャースケールをDAWに入力＆ギターで演奏 / 任意の音から3度・5度・7度を探す【完了】
* **Week 2**: C, Cm, Cmaj7, C7, Cm7, Cm7♭5等をDAWとギターで比較し、同じコードの転回形・配置を変えたBefore / Afterも作る
* **Week 3**: Cメジャーなどの単一キーで複数進行（I→IV→V→I, I→V→vi→IV, vi→IV→I→Vなど）を作成し、安定・移動・緊張・解決の観点で聴き比べる

## Month 2のDTM個人レッスン開始に向けた準備

Month 1の終わりに、最初の個人レッスンで見てもらいたい材料を整理する。

* Month 1短曲の音源
* 自分で良いと思う点を2〜3個
* 自分で違和感がある点を2〜3個
* 「作曲 / アレンジ / 音色 / 演奏 / ミックス」のどこが原因か自分なりに仮説を立てる
* レッスンでは、先生の評価と自分の評価がどこでズレるかを確認する

この最初の音源は、上手く作ることよりも**今の弱点を可視化すること**を目的とする。
