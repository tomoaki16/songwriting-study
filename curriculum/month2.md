# Month 2｜コード進行とメロディ

## 月間目標
コードを並べるだけの状態から、**「どんな感情・流れを作りたいから、このコードを使う」**へ進む。
同時にコードとメロディの関係を理解する。

---

## Weekごとのテーマ

* **Week 5**: コード進行の設計
* **Week 6**: ノンダイアトニックコード
* **Week 7**: メロディの基礎
* **Week 8**: コードとメロディの統合

---

## 学習項目

### Week 5｜コード進行の設計
* **理論**: コード機能の復習 / 強進行 / 弱進行 / 循環 / 終止 / コードチェンジのタイミング / ベースラインとコード進行

### Week 6｜ノンダイアトニックコード
* **理論**: セカンダリードミナント / 借用和音 / modal interchangeの基本 / sus / add9 / slash chord
* *ポイント*: すべてを暗記する必要はなく、ダイアトニック外のコードが入ったときに「何かが起きている」と気づけることが重要。

### Week 7｜メロディの基礎
* **理論**: コードトーン / ノンコードトーン / 経過音 / 隣接音 / アプローチノート / モチーフ / 反復 / 変化 / 音域 / 跳躍 / 順次進行

### Week 8｜コードとメロディの統合
* **理論**: 強拍に置く音 / コードトーンとの関係 / テンション / 7th / 9th / メロディとコードの衝突 / 解決

---

## 分析課題

* **Week 5**: 3曲程度のコード進行を分析。コード単体ではなく「どこで緊張し、どこで解決しているか」を見る。
* **Week 8**: 好きな曲のサビについて、メロディ音 / その瞬間のコード / コードに対する度数 を確認する。

---

## 実践課題

* **Week 5**: 同じメロディに異なるコード進行を付けて印象を比較する。
* **Week 6**: シンプルなダイアトニック進行を作り、一部をノンダイアトニックコードへ変更して比較する。
* **Week 7**: 同じコード進行に対して3種類のメロディを作る（1. コードトーン中心 / 2. 経過音を増やす / 3. 跳躍を増やす）。

---

## 制作課題

* **Month 2制作課題（Week 8）**: 
  * **Song 01の骨格を作る**
  * 最低限、曲のテーマ / コード進行 / メロディ / 大まかな構成 / 仮歌またはメロディ音源 まで作成する。

---

## 月末到達基準

* [ ] コード進行とメロディを別々に作るだけでなく、両者の関係を意識して修正できる
* [ ] ノンダイアトニックコードの役割や効果を意識して使用・検出できる
* [ ] Song 01 の骨格（テーマ、コード、メロディ、大まかな構成）を完成させている
