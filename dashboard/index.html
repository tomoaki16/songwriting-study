オリジナル曲 5曲カンバン・パイプライン

アイデアから骨格制作、フルアレンジ、録音・ミックス、完成までトラック進行を管理します。

音楽理論クイックリファレンス

  • メジャースケール: 全 - 全 - 半 - 全 - 全 - 全 - 半
  • 三和音: Major (1-3-5), Minor (1-♭3-5), Dim (1-♭3-♭5), Aug (1-3-♯5)
  • 7thコード: maj7 (1-3-5-7), 7 (1-3-5-♭7), m7 (1-♭3-5-♭7), m7♭5 (1-♭3-♭5-♭7)
  • コード機能: Tonic (安定/解決), Subdominant (移動/展開), Dominant (緊張/ドミナントモーション)

アレンジ・バンド構成ノート

  • ドラム: Kick (表拍/リズム核), Snare (2・4拍), Hi-hat (8/16分刻み), Fill (セクション繋ぎ)
  • ベース: ルート維持 / 5度・経過音 / キックとの同期（動かしすぎない）
  • ギター: ストローク過多回避。リフ, アルペジオ, 空間音色での役割分担
  • ミックス優先順位: 1.音量 → 2.Pan → 3.EQ → 4.Comp → 5.Reverb/Delay

GitHub & VPS 連携設定

プライベートリポジトリ参照やAPI制限回避用に、ブラウザローカルストレージへ保存します。

VPS デプロイ方法

本ダッシュボードは純粋な静的ファイル（HTML/CSS/JS）です。既存VPS（Nginx / Apache / Docker）の /var/www/songwriting-study または指定ドキュメントルートへ展開してアクセス可能です。 

# VPS上でのクローン・配置例
git clone https://github.com/tomoaki16/songwriting-study.git
cd songwriting-study/dashboard
chmod +x vps/deploy.sh
./vps/deploy.sh
