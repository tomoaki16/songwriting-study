# 使用テキスト対応表

このファイルは、現在使用している作曲テキストを6か月カリキュラムに対応付けるための参照表です。

今後、ChatGPTが日別Issueを新規作成・更新するときは、**必ずこのファイルを先に確認し、その日の学習内容に対応するページを `📖 使用テキスト` としてIssue本文に記載する**こと。

テキストの順番をそのまま学習順にするのではなく、6か月の最終ゴール・月間目標・Week目標を優先し、必要な項目を選択して使用する。未学習範囲を補助的に参照するときは `先取り` と明記する。

## 運用ルール

1. 日別Issue作成前に、この対応表と対象Monthの `curriculum/monthN.md` を確認する。
2. Issue本文に `## 📖 使用テキスト` を置き、ページ番号だけでなく「その日どこまで読む / 何を確認するか」を書く。
3. テキストを読むだけで完了にしない。原則 `Learn → Analyze → Practice → Apply → Review` のどこへ接続するかをIssueに明記する。
4. テキストの全項目を順番に消化することを目的にしない。6か月で5曲完成というゴールに必要な項目を優先する。
5. 発展項目は理解度・自作曲での必要性に応じて後回しにしてよい。
6. 新しい教材ページ情報が判明した場合、このファイルを更新してから関連Issueへ反映する。
