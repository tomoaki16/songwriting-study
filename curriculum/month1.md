# Month 1｜音楽の仕組みと作曲の基礎＋DAW接続

## 月間目標
音・スケール・コード・キー・コード機能・リズム・曲構成について、今後の作曲学習に必要な基礎を体系的に理解する。
暗記だけではなく、**「なぜこのコードが使えるのか」「今鳴っている音が何なのか」**を説明できる状態を目指す。

同時にMonth 1からStudio Oneを毎週使い、学んだ内容を**ギター → DAW → 既存自作曲**へ接続する。

現在Studio One上にイントロ〜Bメロまで制作済みの自作曲が1曲あるため、新しい練習曲を別に作ることを優先せず、この曲を原則 **Song 01** として教材化する。

Month 1終了時には、Song 01の現状版から30〜60秒以上の区間を基準音源として書き出し、**「半年開始時点の自分の判断で作った音源」**を残す。

> 標準教材のページ対応は [`textbook-reference.md`](textbook-reference.md) を参照。日別Issue作成時は、このファイルと教材対応表の両方を確認する。

## 実績に応じた進度調整｜2026-08-19〜20
Week 1は当初7日想定だった内容を**実学習4日間**で完了した。確認テスト、ギター実演、既存曲分析、8小節ミニ実践まで実施しており、単純な読み飛ばしではなく到達基準を満たしたうえでの前倒しと判断する。

今後は以下の方針で進める。

1. **7日分を必ず7日かける運用にはしない**。到達テストを通過したら次へ進む。
2. 余った時間は新規理論の詰め込みだけに使わず、**Analyze / Practice / Apply** を増やす。
3. Week 2以降は、原則として **理論 → ギター → Studio One → Song 01の4〜16小節へApply** を一つの学習サイクルとする。
4. Month 3のドラム・ベース・ギター集中学習は維持し、Month 1でフルアレンジを先取りしない。
5. Week 1で先取りした内容は重複説明を短くし、Week 2はコード語彙の体系化・四和音・転回形・ボイシング・DAWでの配置確認へ時間を振る。
6. Week 3のコード機能は正式学習として残し、Week 2で感じた「帰着感」「緊張感」を理論と接続する。

## Month 1制作課題

新しい30〜60秒短曲を別途作ることは必須としない。

代わりに、Studio One上の既存自作曲（Song 01候補）を使い、以下を行う。

- [ ] 30〜60秒以上の区間を選ぶ
- [ ] Key / コード / メロディ / リズム / 構成を把握する
- [ ] Month 1で学んだ内容を最低2か所試す
- [ ] Before / Afterを比較する
- [ ] 良いと思う点を2〜3個書く
- [ ] 違和感を2〜3個書く
- [ ] Composition / Arrangement / Performance / Mixのどこが原因か仮説を立てる
- [ ] WAV等で書き出し、半年開始時点の基準音源として保存する

## DTM個人レッスン開始条件

暦上のMonth 1終了日ではなく、次の条件を満たした時点を開始目安とする。

- [ ] Month 1の主要基礎到達基準を満たしている
- [ ] Song 01の現状版をStudio Oneから書き出せる
- [ ] 良い点 / 違和感 / 原因仮説を自分の言葉で用意できる

最初のレッスンでは、先生に完成させてもらうのではなく、**現時点で最も弱い能力・改善効果が高い課題・自分の判断とのズレ**を確認する。
