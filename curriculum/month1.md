# Month 1｜音楽の仕組みと作曲の基礎

## 月間目標
音・スケール・コード・キー・コード機能・リズム・曲構成について、今後の作曲学習に必要な基礎を体系的に理解する。
暗記だけではなく、**「なぜこのコードが使えるのか」「今鳴っている音が何なのか」**を説明できる状態を目指す。

---

## Weekごとのテーマ

* **Week 1**: 音名・音程・スケール
* **Week 2**: コードの基本
* **Week 3**: ダイアトニックコードとコード機能
* **Week 4**: リズム・曲構成・Month 1総合

---

## 学習項目

### Week 1｜音名・音程・スケール
* **理論**: 12音 / 半音・全音 / オクターブ / 音程 / 度数 / 完全・長・短 / メジャースケール / スケールの構造 / キー / ルート
* **ギターとの接続**: 6弦すべての基本的な音名 / フレット上の音名 / オクターブポジション / ルート音を素早く探す練習
* **使用テキスト対応**:
  * 04 音名｜p.18
  * 06 調号と臨時記号｜p.22
  * 07 音程｜p.24
  * 08 全音と半音｜p.26
  * 09 メジャースケール（長調）｜p.28
  * Day 2では、Week 2への橋渡しとして 13 メジャーコードとマイナーコードの違い｜p.39 を先取りして長3度・短3度とコードの関係だけ確認する

### Week 2｜コードの基本
* **理論**: 三和音（メジャー, マイナー, diminished, augmented） / ルート・3度・5度 / コード構成音 / 転回形
* **7thコード**: maj7 / 7 / m7 / m7♭5

### Week 3｜ダイアトニックコードとコード機能
* **理論**: ダイアトニックコード（I〜VII） / Tonic / Subdominant / Dominant / 安定と不安定 / 解決 / 終止感

### Week 4｜リズム・曲構成
* **リズム基礎**: BPM / 拍 / 小節 / 4/4 / 8分音符 / 16分音符 / 休符 / シンコペーション / 表拍・裏拍
* **曲構成**: Intro / Verse（Aメロ） / Pre-Chorus（Bメロ） / Chorus（サビ） / Interlude / Bridge（Cメロ） / Outro

---

## 分析課題

* **Week 1**: 好きな曲のキーを1曲調べる
* **Week 2**: 同じコードでもルート・3度・5度・7度の配置によって響きがどう変わるか確認する
* **Week 3**: 好きな曲を1曲選び、キー・コード・ディグリー・コード機能を書き出す
* **Week 4**: 2〜3曲について、セクション / 小節数 / コード進行 / 楽器の増減 を記録する

---

## 実践課題

* **Week 1**: CメジャースケールをDAWに入力＆ギターで演奏 / 任意の音から3度・5度・7度を探す
* **Week 2**: C, Cm, Cmaj7, C7, Cm7 などをDAWとギターで比較する
* **Week 3**: Cメジャーなどの単一キーで複数進行（I→IV→V→I, I→V→vi→IV, vi→IV→I→Vなど）を作成し、安定・移動・緊張・解決の観点で聴き比べる

---

## 制作課題

* **Month 1制作課題（Week 4）**: 
  * 30〜60秒程度の短い曲を作る
  * 完成度よりも、キー / コード / メロディ / リズム / 構成 を意識して組み立てる
