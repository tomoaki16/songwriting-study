# Month 1｜音楽の仕組みと作曲の基礎＋DAW接続

## 月間目標
音・スケール・コード・キー・コード機能・リズム・曲構成について、今後の作曲学習に必要な基礎を体系的に理解する。
暗記だけではなく、**「なぜこのコードが使えるのか」「今鳴っている音が何なのか」**を説明できる状態を目指す。

同時にMonth 1からStudio Oneを毎週使い、学んだ内容を**ギター → DAW → 既存自作曲**へ接続する。

Song 01は現在、**ギターのコード進行＋ベースフレーズのみ**。曲全体・メロディ・ドラム等は未完成であり、Month 1では新しい練習曲を別に作ることを優先せず、このSong 01を理論学習の実験台として使う。

> 標準教材のページ対応は [`textbook-reference.md`](textbook-reference.md) を参照。日別Issue作成時は、このファイルと教材対応表の両方を確認する。

## 実績に応じた進度調整｜2026-08-19〜23
Week 1は当初7日想定だった内容を**実学習4日間**で完了。Week 2は**実学習7日目＋8日目23分でReviewまで完了**した。確認テスト、ギター実演、既存曲分析、Studio One / Song 01へのApplyまで実施しており、読み飛ばしではなく到達基準を満たした前倒しと判断する。

今後は以下の方針で進める。

1. **7日分を必ず7日かける運用にはしない**。到達テストを通過したら次へ進む。
2. Week 3も7学習Issueを基本単位として用意するが、理解済み部分は短く通過し、同一実日で複数Issueへ進んでよい。
3. 余った時間は新規理論の詰め込みだけに使わず、**Analyze / Practice / Apply** を増やす。
4. 原則として **理論 → ギター → Studio One → Song 01の4〜16小節へApply** を一つの学習サイクルとする。
5. Month 3のドラム・ベース・ギター集中学習は維持し、Month 1でフルアレンジを無理に先取りしない。
6. Week 3ではWeek 1〜2で耳で確認した「帰着感」「緊張感」「転回形による展開」を、Tonic / Subdominant / Dominant、Degree、Cadenceへ接続する。

## 学習項目

### Week 1｜音名・音程・スケール
* **理論**: 12音 / 半音・全音 / オクターブ / 音程 / 度数 / 完全・長・短 / メジャースケール / スケールの構造 / キー / ルート
* **ギターとの接続**: 開放弦 / フレット上の音名 / オクターブポジション / ルート音探索
* **使用テキスト**: 04 p.18 / 06 p.22 / 07 p.24 / 08 p.26 / 09 p.28、必要に応じて10 p.32 / 11 p.34

### Week 2｜コードの基本＋DAW接続
* **理論**: major / minor / dim / 7th / 四和音ダイアトニック / 転回形 / ボイシング / ベース音
* **Studio One / Song 01**: 7th・転回形・ボイシングを実曲へApplyしBefore / Afterを比較
* **使用テキスト**: 12 p.37 / 13 p.39 / 14 p.42 / 15 p.44 / 16 p.46 / 17 p.48 / 18 p.50

### Week 3｜ダイアトニックコードとコード機能
* **理論**: I〜VII / Tonic / Subdominant / Dominant / 安定と不安定 / 解決 / 終止感 / Degree / Cadence
* **Studio One**: 同じキーで機能の異なる進行を入力し、安定・移動・緊張・解決を比較
* **Song 01 Apply**: 現在のコード進行をDegreeとFunctionで分析し、感覚で作った箇所の理由を言語化。Aメロ〜Bメロ接続やBメロ候補 **F#m7 → B7 → G#m7 → C#m7** を教材として使う
* **使用テキスト**:
  * 12 / 15 ダイアトニックコード｜p.37 / p.44
  * 19 コードの機能｜p.54
  * 20 ケーデンス｜p.58
  * 28 ディグリーネーム｜p.78

### Week 4｜リズム・曲構成・Month 1総合
* **リズム**: BPM / 拍 / 小節 / 4/4 / 8分・16分 / 休符 / シンコペーション / 表拍・裏拍
* **曲構成**: Intro / Verse / Pre-Chorus / Chorus / Interlude / Bridge / Outro
* **Studio One**: Song 01の現状セクションをタイムライン上で整理し、BPM / 小節数 / 各パートの入り / 抜けを確認
* **使用テキスト**: 01 p.10 / 02 p.14 / 03 p.16
